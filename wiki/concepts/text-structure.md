# Text Structure

**What it is.** The rhetorical/organizational shape of a text (cause–effect, compare–contrast, hierarchy of topics) and how layout signals it. Corresponds to the matrix's **L5 rhetorical scaffolding** + **V5 layout-structure mapping** ([[concepts/latent-factor-matrix]]).

**Key patterns.**
- Aligning format to structure aids comprehension/summarization [[sources/ej1486502]] · [[sources/18_63]]; web structural elements predict difficulty [[sources/martin-calpena-web-comprehension-2022]].
- Headings signal structure and guide processing [[sources/lemarie-lorch-perywoodley-2012-headings]] · [[sources/functional-headings-selective-attention]] — see [[concepts/headings-signaling]].
- Readers process topic structure differently (strategy typology) [[sources/hyona-lorch-kaakinen-2002-reading-to-summarize]]; macrostructure is central to comprehension theory [[sources/kintsch-1998-comprehension]].
