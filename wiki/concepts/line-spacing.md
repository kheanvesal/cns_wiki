# Line Spacing (Leading)

**What it is.** Vertical space between lines of text.

**Evidence.**
- **Proofreading (Chinese, screen):** line spacing has significant main + interaction effects on proofreading time and detection rate [[sources/chan-2014-line-length-spacing-proofreading]]; eye-tracking shows spacing reshapes fixations [[sources/huang-2017-line-spacing-simplified-chinese]].
- **Comprehension:** no significant effect of line spacing on speed/comprehension in EFL print [[sources/ej1079769]] or mobile [[sources/interletter-line-spacing-reading-speed-comprehension]] — but it can change **comfort**.
- Classic: leading interacts with type size and line length [[sources/tinker-1963-legibility-of-print]]; craft guidance proportional to measure/size [[sources/bringhurst-elements-of-typographic-style]].

**Pattern.** Line spacing more clearly affects **proofreading/eye-movements** and **comfort** than it affects **comprehension** outcomes — a task-dependent divergence.
