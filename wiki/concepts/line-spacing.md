# Line Spacing (Leading)

**What it is.** Vertical space between lines of text.

**Evidence.**
- **Proofreading (Chinese, screen):** line spacing has significant main + interaction effects on proofreading time and detection rate [[sources/chan-2014-line-length-spacing-proofreading]]; eye-tracking shows spacing reshapes fixations [[sources/huang-2017-line-spacing-simplified-chinese]].
- **Comprehension:** no significant effect of line spacing on speed/comprehension in EFL print [[sources/ej1079769]] or mobile [[sources/interletter-line-spacing-reading-speed-comprehension]] — but it can change **comfort**.
- Classic: leading interacts with type size and line length [[sources/tinker-1963-legibility-of-print]]; craft guidance proportional to measure/size [[sources/bringhurst-elements-of-typographic-style]].
- **Mechanism: the return sweep.** Line spacing "has a great effect on having an easy return sweep" — when the eyes finish a line they sweep back to the start of the next. If spacing is "not too much or too little, the return sweep occurs easier and faster" [[sources/tarasov-legibility-of-textbooks-2015]]. This makes leading non-monotonic, which fits the general pattern below: it is a **scanpath-navigation** variable, not a decoding one.
- **Dyslexia: no group signal.** Dyslexia status did **not** predict spacing (`p=.436`), even though it *did* predict font size — though atypical readers did select wider letter spacing (40.8% at level 4 vs. 34.5% of typical readers at level 1) [[sources/validating-personalized-visual-auditory-parameters-dyslexia]].

## ⚠️ Measurement standard
Leading cannot be compared across studies unless expressed **as a fraction of x-height** (or in mm) alongside typeface and type size, because "1.5 lines" denotes very different absolute space in different faces [[sources/tarasov-legibility-of-textbooks-2015]]. None of the studies above reports that normalization. See [[concepts/methodology-critique]].

**Pattern.** Line spacing more clearly affects **proofreading/eye-movements** and **comfort** than it affects **comprehension** outcomes — a task-dependent divergence. The return-sweep account explains why: it governs where the eye goes next, which matters when scanning or proofreading, and much less when decoding continuous prose.
