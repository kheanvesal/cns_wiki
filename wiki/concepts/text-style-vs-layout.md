# Text Style vs. Layout (and the bridge between)

An analytical distinction that runs through the whole corpus. It is **not a filing partition** — source pages stay organized by reading task — but a lens for reading the evidence. The distinction matters because the two groups behave differently: it maps almost exactly onto **threshold vs. control** (see [[syntheses/reading-goal-x-controlling-latent-factors]]).

## 1. Text style / typography — *glyph-level*
How the letters themselves look. Corresponds to the matrix's **V2 glyph legibility**.
Members: [[concepts/font-type-typeface]] · [[concepts/font-size]] · [[concepts/serif-vs-sans]] · [[concepts/letter-case]] · [[concepts/disfluency]] · [[concepts/legibility]].

**Verdict: mostly a threshold variable.** Below legibility everything fails; above it, more/better glyph styling buys **speed and comfort, not comprehension**. Rarely *controls* any goal's outcome ([[sources/ej1079769]], [[sources/richardson-legibility-serif-sans-serif]], [[sources/dykes-sans-forgetica-readability]]).

## 2. Layout — *spatial & structural arrangement*
How text and elements are arranged on the page/screen. Corresponds to matrix **V1 (partly), V3, V4, V5, V6**.
Members: [[concepts/line-length]] · [[concepts/columns]] · [[concepts/whitespace-margins]] · [[concepts/headings-signaling]] · [[concepts/text-structure]] · [[concepts/information-density]] · [[concepts/layout-topology]] · [[concepts/scrolling-vs-paging]] · [[concepts/interaction-style]] · [[concepts/graphic-organizers]] · [[concepts/text-graphic-integration]].

**Verdict: where the control lives.** Structure, salience, density, and navigation are the factors that actually **move** comprehension, search, and skim outcomes.

## 3. Bridge variables — *span both*
Set at the glyph/line level but functioning spatially — do **not** force these into one bucket:
- [[concepts/line-spacing]] and [[concepts/letter-spacing]] — glyph-level settings, but spatial (matrix lumps them into V1 spatial density).
- [[concepts/emphasis-bold-italic]] — glyph marks whose *function* is salience/signaling (a layout job).
- [[concepts/characters-per-line]] / [[concepts/line-length]] — a layout variable tightly coupled to font size.

**Why the bridge matters.** These are exactly where **text-style × layout interactions** live (e.g., optimal cpl depends on font size), and the corpus almost never crosses two factors in one study — so the bridge set is the home of the biggest evidence gaps ([[concepts/latent-factor-matrix]] "single-axis isolation").

## A third layer: content (Gen-AI)
Text style and layout both act on *presentation*. LLMs open a distinct lever — the **content/linguistic** layer (compression via summaries, cohesion/level via rewriting) — which is neither text style nor layout. It reaches comprehension more directly than either, and is the emerging Gen-AI frontier ([[syntheses/gen-ai-and-reading]]). So the fuller stack is **content → layout → text style**, floor-to-ceiling in reverse: content moves the ceiling most, text style least.

## One-line takeaway
**Text style sets the floor; layout moves the ceiling; content (now LLM-manipulable) moves it most — and the interactions are the least-studied, highest-value frontier.**
