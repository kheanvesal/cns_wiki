# Reading Comfort / Preference / Aesthetics

**What it is.** Self-reported subjective response to a text's presentation — comfort, preference, aesthetic appeal. A method type distinct from performance ([[concepts/method-type-divergence]]).

**Key patterns — preference ≠ performance.**
- Spacing changes comfort without changing speed/comprehension [[sources/interletter-line-spacing-reading-speed-comprehension]].
- Sparse layouts preferred but dense faster [[sources/tarling-2009-page-layout-visual-search]].
- Proofreading/whitespace: preferred ≠ objectively best settings [[sources/chan-ng-display-factors-chinese-proofreading]] · [[sources/2534-handheld-whitespace-reading]].

**Implication.** Comfort/preference is a legitimate outcome (adoption, fatigue) but must not be read as evidence of performance.
