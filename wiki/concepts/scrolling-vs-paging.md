# Scrolling vs. Pagination

**What it is.** How on-screen text is navigated — continuous scrolling vs. discrete pages. Matrix axes **V4 temporal presentation** / **V6 navigation structure**.

**Key patterns.**
- Scrolling vs. pagination for within-document search interacts with **screen size** [[sources/hemminger-marcial-2012-scrolling-pagination]].
- Line length/number drive **scrolling amount**, a cost distinct from accuracy in proofreading [[sources/chan-2014-line-length-spacing-proofreading]].
- Scrolling patterns relate to comprehension in fast screen reading [[sources/dyson-haselgrove-2000-speed-patterns-screen]]; multi-slate layouts rethink navigation [[sources/chen-multislate-active-reading]].

**Gap (from matrix).** The tiered/collapsible end of the navigation range is under-sampled; true externally-paced (RSVP) presentation is absent.
