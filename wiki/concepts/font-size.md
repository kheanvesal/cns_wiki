# Font Size

**What it is.** The point size of type.

**Evidence.**
- Larger size aids **speed/legibility**: 12pt read faster than 10pt (EFL print) — but **no** effect on comprehension/recall [[sources/ej1079769]].
- Size affects **eye-movement** behavior online (fixation duration/number) [[sources/beymer-font-size-type-online-reading]].
- Classic optima ~9–12pt read fastest; extremes hurt [[sources/tinker-1963-legibility-of-print]].

**Pattern.** Size helps legibility/speed and eases eye movements; it does **not** by itself raise comprehension once text is legible. Interacts with line length and spacing.
