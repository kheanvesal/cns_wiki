# Legibility

**What it is.** The ease/speed with which text can be visually decoded — distinct from **comprehension** (understanding). Operationalized via reading speed, visibility distance, and error/detection rates.

**Key evidence.**
- Foundational optima: type size ~9–12pt, moderate line length, adequate leading, avoid all-caps [[sources/tinker-1963-legibility-of-print]].
- Legibility gains (e.g., larger size) raise **speed** but not necessarily **comprehension** [[sources/ej1079769]].
- Serif/sans legibility differences are weak once controlled [[sources/richardson-legibility-serif-sans-serif]] · [[sources/lund-1999-knowledge-construction-typography]].
- Skimming of clinical text manipulates legibility × task [[sources/soltan-2026-skimming-clinical-info-eyetracking]].

**Critical distinction.** Legibility ≠ comprehension. Style variables often move legibility/speed while leaving deep comprehension unchanged (unless text is hard enough that freeing resources helps).
