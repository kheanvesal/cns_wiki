# Cognitive Processes in Reading Comprehension: A Theoretical Framework for Foreign Language Acquisition

**Citation.** Todorova, M. (2024). Cognitive Processes in Reading Comprehension: A Theoretical Framework for Foreign Language Acquisition. *International Journal of Advanced Natural Sciences and Engineering Researches (IJANSER)*, 8, 162–170.

**Reading task(s).** Comprehension (theoretical, FL/EFL).

**Question/aim.** Provide a theoretical framework for the cognitive processes underlying reading comprehension in foreign-language acquisition.

**Method.** Theoretical/conceptual review.

**Style/layout variables manipulated.** None — cognitive-process framework (decoding, working memory, inference, metacognition); context, not a style study.

**Key findings.**
- Frames FL reading comprehension as interacting lower-level (decoding) and higher-level (inference, integration) processes.
- Emphasizes working memory and strategy/metacognition in comprehension.
