# The Influence of Target Layout and Target Graphic Type on Searching Performance Based on Eye-Tracking Technology

**Citation.** Zuo, Y., Qi, J., Fan, Z., Wang, Z., Xu, H., Wang, S., Zhang, N., & Hu, J. (2023). The influence of target layout and target graphic type on searching performance based on eye-tracking technology. *Frontiers in Psychology*, 14, 1052488.

**Reading task(s).** Search (interactive interfaces / icons).

**Question/aim.** Effects of icon layout location, icon graphic type (**facet vs. linear**), and layout method on search performance.

**Method.** Eye-tracking; search tasks for a target icon across images; 36 trials/participant; metrics: search time, fixation duration, fixation count.

**Style/layout variables manipulated.** Icon graphic type (facet vs. linear); icon layout location; layout method (e.g., rectangular vs. other).

**Key findings.**
- With **familiar icons**, facet vs. linear graphic type did **not** affect experience.
- When other interface factors changed, **facet icons** gave a more stable experience.
- Layout location/method affected search performance (details in paper).

**Effect direction & size.** Graphic-type effect null for familiar icons; facet more robust under interface variation.

**Limitations/caveats.** Interface/icon domain (not prose); familiarity strongly moderates.
