# The Effect of Text Typographical Features on Legibility, Comprehension, and Retrieval of EFL Learners

**Citation.** Soleimani, H., & Mohammadi, E. (2012). The Effect of Text Typographical Features on Legibility, Comprehension, and Retrieval of EFL Learners. *English Language Teaching*, 5(8), 207–. doi:10.5539/elt.v5n8p207.

**Reading task(s).** Comprehension + legibility (print, EFL).

**Question/aim.** Whether font type, font size, and line spacing affect legibility (reading speed), comprehension, and recall.

**Method.** Experimental; print materials in 8 typographical styles. N=90 (legibility), N=76 (comprehension); recall test 2 weeks later. Factors: font (Arial vs. Bookman Old Style) × size (10pt vs. 12pt) × spacing (solid vs. double).

**Style/layout variables manipulated.** Font type, font size, line spacing (leading).

**Key findings.**
- 12pt read significantly faster than 10pt.
- Font selection and line spacing did **not** significantly affect reading speed.
- No significant effects on comprehension or recall for any factor.

**Effect direction & size.** Size effect on speed only (12pt > 10pt); null for comprehension/recall. Sizes not reported.

**Limitations/caveats.** Print only; EFL sample; limited font set; behavioral speed/accuracy, no eye-tracking.
