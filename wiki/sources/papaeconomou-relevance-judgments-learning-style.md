# Searchers' Relevance Judgments and Criteria in Evaluating Web Pages in a Learning Style Perspective

**Citation.** Papaeconomou, C., Zijlema, A. F., & Ingwersen, P. (2008). Searchers' Relevance Judgments and Criteria in Evaluating Web Pages in a Learning Style Perspective. *IIiX '08 (Information Interaction in Context)*. Royal School of Library and Information Science, Copenhagen.

**Reading task(s).** Search (relevance evaluation of web pages).

**Question/aim.** Which criteria searchers use to judge web-page relevance, and whether **learning style** (cognitive style) shapes those judgments.

**Method.** User study of relevance judgments; criteria analysis; learning-style grouping.

**Style/layout variables manipulated.** None typographic — focuses on *relevance criteria* and reader **cognitive/learning style** as a moderator; layout enters via which page features drive relevance.

**Key findings.**
- Searchers apply a range of content/format relevance criteria when evaluating pages.
- Learning style is associated with differences in judgment criteria (individual-difference moderator of search behavior).

**Effect direction & size.** Qualitative/criteria-analytic; no standardized effect size.

**Limitations/caveats.** "Learning style" constructs are contested; small IR user study.
